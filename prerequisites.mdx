Install the tools below before using Scaffold Stacks. All versions listed are minimums.

<Tip>
  Run `stacksdapp doctor` after installing the CLI — it checks Rust, Node, Clarinet 3.23+, Docker, and git in one pass.
</Tip>

## Requirements

| Tool | Minimum version | Required for |
| --- | --- | --- |
| Rust | 1.75+ | Building and installing the CLI |
| Node.js | 20+ | Frontend and contract tests |
| Clarinet | 3.23+ | Contract toolchain and Clarity 6 devnet |
| Leather or Xverse | latest | Testnet and mainnet wallet flows |
| Docker Desktop | latest | Local devnet only |

## Install the CLI

```bash
cargo install stacksdapp
stacksdapp --version
```

Or build from source:

```bash
git clone https://github.com/scaffold-stack/scaffold-stack.git
cd scaffold-stack
cargo install --path cli
```

## Verify installation

```bash
stacksdapp doctor
```

Checks Rust, Node.js, Clarinet 3.23+, Docker (for devnet), git, and git hooks path.

For CI pipelines, use strict mode to fail on warnings:

```bash
stacksdapp doctor --strict
```

To verify manually:

```bash
rustc --version && node --version && clarinet --version
```

If `doctor` passes, continue to the [quickstart](/quickstart).

## Rust

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
rustup update
```

Verify:

```bash
rustc --version
```

## Node.js

```bash
# Using nvm (recommended)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install 20
nvm use 20
```

Verify:

```bash
node --version
npm --version
```

## Clarinet

Scaffold Stacks templates target Clarinet SDK 3.23+ and default to **Clarity 6** (epoch 4.0).

```bash
# macOS with Homebrew
brew install clarinet

# Or build from source
git clone https://github.com/stx-labs/clarinet
cd clarinet
cargo install --path .
```

Verify:

```bash
clarinet --version
```

Clarinet 3.23+ is required for Clarity 6 devnet. Testnet and mainnet deploy work with earlier 3.21+ releases, but `stacksdapp doctor` expects 3.23+.

## Stacks wallet

Install a browser wallet and create a testnet account:

- [Leather](https://leather.io/)
- [Xverse](https://www.xverse.app/)

## Docker (optional)

Required only for [local devnet](/local-devnet):

```bash
# macOS
brew install --cask docker
```
