Deploy your first Stacks dApp to testnet in minutes. No Docker required.

<Tip>
  Requires Clarinet **3.23+**. Verify with `stacksdapp doctor` before you start.
</Tip>

<Steps>
<Step title="Install the CLI">

```bash
cargo install stacksdapp
stacksdapp --version
stacksdapp doctor
```

Or build from source:

```bash
git clone https://github.com/scaffold-stack/scaffold-stack.git
cd scaffold-stack
cargo install --path cli
```

</Step>

<Step title="Scaffold a project">

```bash
stacksdapp new my-app
cd my-app
```

This creates a counter contract (Clarity 6), Next.js frontend, network settings, `stacksdapp.toml`, and a bundled agent skill.

Skip git init with `stacksdapp new my-app --no-git`.

</Step>

<Step title="Get testnet STX">

1. Open the [Hiro testnet faucet](https://explorer.hiro.so/sandbox/faucet?chain=testnet)
2. Add your deployer mnemonic to `contracts/settings/Testnet.toml`:

```toml
[accounts.deployer]
mnemonic = "your 24 words here"
```

<Warning>
  Never commit real mnemonics. The pre-commit hook blocks likely seed phrases in Testnet.toml and Mainnet.toml.
</Warning>

</Step>

<Step title="Deploy to testnet">

```bash
stacksdapp check && stacksdapp generate && stacksdapp test
stacksdapp deploy --network testnet --yes
```

Preview fees without broadcasting:

```bash
stacksdapp deploy --network testnet --dry-run
```

Addresses are written to `frontend/src/generated/deployments.json`.

</Step>

<Step title="Start the frontend">

```bash
stacksdapp dev --network testnet
```

Opens [http://localhost:3000](http://localhost:3000). The Debug Contracts panel lists every contract function with typed inputs.

Connect Leather or Xverse set to Testnet. Public functions open a wallet popup; read-only functions call the node directly.

</Step>
</Steps>

<Note>
  You now have a live Stacks dApp on testnet. Use the debug UI to interact with your contracts.
</Note>
