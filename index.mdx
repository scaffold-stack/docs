Scaffold Stacks is a Rust CLI (`stacksdapp`) and Next.js template for building full-stack Stacks (Bitcoin L2) dApps. It generates type-safe TypeScript bindings from Clarity contracts, ships a live debug UI, and supports one-command deployment to testnet, mainnet, or local devnet.

If you are new, start with the quickstart. If you already have a Clarinet project, use the adopt guide. For command syntax, see the CLI reference tab.

## Key features

- **Auto-generated TypeScript bindings**: Type-safe code from Clarity ABIs, with ABI caching for fast regenerate
- **Live debug UI**: Interactive forms for every contract function
- **One-command deployment**: Testnet, mainnet, or local Docker devnet (optional `--auto-deploy`)
- **Contract templates**: SIP-010 tokens and SIP-009 NFTs
- **Adopt existing Clarinet projects**: `stacksdapp init` without starting from scratch
